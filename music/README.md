# Músicas de fundo (opcional)

Coloque aqui arquivos .mp3/.wav de músicas **royalty-free** que você baixou
uma vez (download único, sem custo recorrente, sem crédito), por exemplo:

- YouTube Audio Library (studio.youtube.com → Áudio) — grátis
- Pixabay Music (pixabay.com/music) — grátis, sem necessidade de crédito
- Free Music Archive (freemusicarchive.org) — checar a licença de cada faixa

Eles aparecem automaticamente no menu "Música de fundo" da interface web e
no parâmetro `--music` do `edit.py`. O app aplica volume baixo com "duck"
automático (abaixa a música sozinha quando tem fala).

# Efeitos sonoros (opcional, pro modo chat)

Coloque aqui arquivos .mp3/.wav de efeitos sonoros **royalty-free** que você
baixou uma vez (download único, sem custo recorrente, sem crédito), por
exemplo:

- Pixabay Sound Effects (pixabay.com/sound-effects) — grátis
- Mixkit (mixkit.co/free-sound-effects) — grátis
- freesound.org — filtre por licença CC0 (domínio público)

Sugestões de nomes pra facilitar (o diretor de IA vai ver os nomes dos
arquivos que estiverem aqui e pode sugerir usá-los quando fizer sentido):
`whoosh.mp3`, `camera-shutter.mp3`, `pop.mp3`, `ding.mp3`.

Sem nenhum arquivo aqui, o modo chat funciona normalmente — só não vai
oferecer efeito sonoro nenhum.
